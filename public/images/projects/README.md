# Project Screenshots

Drop your project screenshot images here.

## How to Use

Place images in this folder, then reference them in `data/portfolio.ts`:

```ts
image: "/images/projects/your-filename.png"
```

## Naming Convention

| Project | Suggested filename |
|---------|-------------------|
| Honor POS & Inventory | `honor-pos.png` |
| Kyusify | `kyusify.png` |
| Disaster Simulation | `disaster-sim.png` |

## Tips

- Recommended size: **1200 × 630px** (16:9 or similar wide ratio)
- Formats: `.png`, `.jpg`, or `.webp`
- Keep file sizes under **500KB** for fast loads (use https://squoosh.app to compress)
- Screenshots work best with a full browser window or the app's dashboard view
